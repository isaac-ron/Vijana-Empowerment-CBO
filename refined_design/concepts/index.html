Three ways the homepage could look.

Each direction is a complete, working landing page for the same organisation, built from the references you shared and tuned for a youth-empowerment audience. Open any one full screen, then we narrow to the one that fits.

Faithful to the logo throughout: the brick-red and orange palette and the iris-and-hands mark. What changes between concepts: a different headline typeface per direction, plus pacing, layout, and how loud the type runs.
